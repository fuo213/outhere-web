Design system v0.1. A field notebook for planning multi-day trips: warm paper, precise ink, one rust accent, and motion that confirms what you did.

v0.1 · 2026-11-07

Principles

Each one has a test. A screen that fails the test is wrong even if it looks nice.

The map is the hero

Chrome frames the map and gets out of the way.

Test: the map owns most of the viewport; one panel at a time.

One clear next step

Exactly one primary action per view. Empty states say what to do next.

Test: squint, and you see exactly one rust-filled element.

Ink on paper

Paper surfaces, near-black ink, rust for action. Type colors mean kinds of places.

Test: remove every color but rust and the type colors and nothing important is lost.

Quiet type, loud numbers

Playfair for titles, DM Sans for UI, Plex Mono for numbers. Sentence case.

Test: nothing below 11px; mono never sets words.

Motion confirms, never decorates

Six verbs, each triggered by something the user did.

Test: idle UI is still; under reduced motion nothing moves.

Honest and specific

Name real things. Promise only what ships.

Test: no exclamation marks, no features a user can't use today.

Trip panel, rebuilt from the system

A sketch, not the app: the planner panel composed only from tokens and base components. One primary action, numbers in mono, days that show what's in them, labeled tools.

Motion

Six verbs. Each one answers "did that work?" or "where did that go?". Turn on Reduce Motion in your OS and everything still works without moving.

press

Every button sinks when pressed and springs back.

lift

Things you can grab rise on hover.

confirm

flip

Two-state toggle. Hover previews the other state.

draw

A finished route draws itself in.

count

Totals tick to their new value after an edit.
